## 🚀 What We Do  

At Epic Fight Studios, we design, build and deliver:  
- Custom mods, plugins and tools for enhanced combat mechanics.  
- Original content and features that enrich gameplay and community experience.  
- Clear, well-documented code and assets, for both users and fellow developers.  

Whether you want to play, contribute, or build on top of our work, you’re welcome here.

<img src="https://i.imgur.com/CWsUfxt.jpg" alt="Bold Breakline" width="1344" height="48" />

## 🛠️ Contributing & Collaboration  

We encourage collaboration! Here’s how you can join:  

1. Browse our **projects/** directory and pick something that interests you.    
2. Make your changes, document them properly, and submit a Pull Request.  
3. After review, we’ll merge if everything aligns.  

Check each project’s `CONTRIBUTING.md` for specific guidelines.
